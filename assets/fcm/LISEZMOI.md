# Clé d'envoi FCM (module Véhicules)

Mettre ici la clé du compte de service Firebase, renommée
`service_account.json` (Console Firebase > Paramètres du projet >
Comptes de service > Générer une nouvelle clé privée).

Ce fichier est SECRET : il est ignoré par Git (.gitignore) et ne doit
jamais être publié. Sans lui, l'appli fonctionne mais n'envoie pas de
notifications.
